## 후속 수동 검증 절차

아래 절차는 아직 실행하지 않았다. 결과를 관찰하기 전까지 모두 미확인이다.

1. 기존 작업을 백업하고 검증 전용 캐릭터를 만든다. 종족·커리어·필수 선택을 완료한 후 시트 전환과 시작 수치·XP·재산을 기록한다. 필수 선택을 누락했을 때 완료가 차단되는지도 확인한다.
2. 능력치·기술·재능별로 구매 비용과 현재 수치를 기록하고 충분한 XP를 지급한다. 한 번 성장시킨 뒤 XP가 정확히 비용만큼 줄고, 성장 횟수·수치·이력이 함께 반영되는지 확인한다.
3. 다음 성장 비용을 C라 할 때 XP 0 및 C-1에서 버튼 비활성화와 성장 불가를 확인한다. 시트·추적 칸·이력이 변하지 않아야 한다. XP가 정확히 C일 때는 성장 성공과 잔여 XP 0을 확인한다. 승급도 추적 조건을 충족한 상태에서 99/100 XP 경계를 별도로 확인한다.
4. 구매 전후 재산·수량을 비교한다. 구매품의 소지 상태와 장착 상태를 구분하고 장착·해제에 따른 시트/AP 변화를 비교한다. 같은 부위 방어구 교체와 여러 부위 방어구의 충돌 해제도 확인한다.
5. 이름·종족·커리어·XP·성장·재산·구매품·장착 상태를 기록하고 저장한다. 값을 바꾼 뒤 불러오기로 저장 시점의 상태가 복원되는지 비교한다. 새로고침 후 저장 목록에서 다시 불러오는 경우와 불러오기 취소 시 현재 상태 보존도 확인한다.

## 결론

로컬 v49에는 요청 기능의 구현 경로와 일반 성장의 XP 부족 차단 코드가 있다. 직접 실행을 완료하지 못했으므로 기능 전체를 정상 또는 검증 통과로 판정하지 않는다. 공개 페이지와 로컬 파일의 동일성도 미확인이다.
